# Runember Windows 快速上手

原 Agentdesk 已更名为 Runember。请使用[安装与首次配置](install.md)、[Agent 自动安装说明](INSTALL_FOR_AGENTS.md)和[故障排查](troubleshooting.md)。

旧的 `desk.cmd`、`Start Agentdesk.cmd`、配置目录和任务记录继续兼容。新版安装包自带 Node.js、Web 和运行时；只需安装 Git 以及至少一个已登录的 Agent。

已有用户升级前应等待任务结束并停止旧后台服务，避免多实例连接钉钉。更换程序目录不会自动迁移或删除任务数据与历史日志。
